# Hermes profiles

Open **Hermes → Profiles** on web or desktop to view profiles on the connected host.
Choose an existing profile to edit its model, provider, reasoning effort and ACP
toolsets, then save. Changes apply to new Hermes sessions. If Hermes warns about a
model's cost or suitability, approve that specific selection before saving it.

Create a fresh profile when you want independent memory and skills. Creation does
not copy credentials. Configure its model and sign in through Hermes if needed,
then choose **Enable as a T3 provider**. This adds a selectable provider without
changing existing providers. The Hermes profile selector controls the Memory,
Skills and Tasks panels; the chat model picker controls the profile used for chat.

This tab requires the Hermes build with the profile JSON interface. Older builds
show an update message. Mobile continues to use its existing default-profile view.
